About This Landscape

The openDesk Edu Landscape is an interactive map of the open-source services that make up the openDesk Edu platform. Inspired by the CNCF Landscape, this visualization helps institutions, IT administrators, and developers understand the complete ecosystem.

How to Use

  • Search for specific services, categories, or tags
  • Filter by service tier (Critical, High, Standard, Low) or maturity
  • Click on any service to see details, documentation, and repository links
  • Browse by category to understand the ecosystem structure
  • Export the full service list as CSV or JSON

Contribute

This landscape is open-source and community-driven. To add a new service, update information, or suggest improvements, please open a pull request on GitHub. The data is stored in data/services.yaml — edit this file, then run npm run build to regenerate the JavaScript.
